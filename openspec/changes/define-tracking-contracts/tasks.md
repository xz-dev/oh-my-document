- [x] 4.2 实现新建/追加范围、0 起点左闭右开坐标、文本/byte 区分、编码优先级及历史视图保存；验证同坐标独立范围、Unicode scalar/BOM/CRLF、多字节编码、非法解码和越界拒绝，配置变化不重新解释历史。
- [x] 4.3 实现完整旧新来源的 hash/Myers 比较及候选迁移；验证局部变化只影响相关范围，位置迁移须复核，`校验密码。` 后紧贴新增 `记录日志。` 使旧范围变脏且不自动扩张，空白修改不能因覆盖过滤被忽略。
